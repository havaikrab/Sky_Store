# Sky Store

## Описание:
Sky Store - это проект, созданный в рамках обучения языку программирования Python.   
Sky Store запланирован как сервер интернет-магазина, созданный с использованием фреймворка Django.  
По освоения новых приемов работы с Django функционал сервера будет постепенно расширяться.

## Цель проекта:
Главной целью Sky Store является закрепление полученных знаний и навыков работы с фреймворком Django.  
А также повторение материала предыдущих уроков, и применение всех полученных знаний на практике, то есть, для решения  
задач, приближенных к реальным.


## Установка:
1. Запустите IDE на локальном ПК.


2. Клонируйте Sky Store из удаленного репозитория.

    Для этого можно из текущей директории на вашем ПК можно ввести в терминале команду:  
git clone git@github.com:havaikrab/Sky_Store.git


3. Установите зависимости.

    В проекте используется менеджер зависимостей Poetry, установите его, при необходимости.
    Для установки зависимостей введите в терминале команду: poetry install  

4. Для работы приложения используется СУБД PostgreSQL, для запуска  
сервера приложения ее необходимо установить "вручную", создать базу данных  
и указать все необходимые настройки для подключения к ней в файле .env  
в корне проекта. В файле .env_template представлен шаблон с необходимыми настройками для подключения к БД.

## Запуск:
Активируйте виртуальное окружение.  
Примените миграции с помощью команды python manage.py migrate.  
Запустите сервер приложения с помощью команды python manage.py runserver.  
После этого в браузере введите адрес localhost:8000  

## Содержимое:
После запуска вам станет доступна страница "Каталог", на которой, по мере публикации новых продуктов
будет размещена информация о них. На странице размещается до 8-ми карточек продуктов,
карточками есть навигационная панель, позволяющая переходить к определенной странице каталога.
В данный момент сервис ограничен 3-мя страницами "Каталог", "Контакты", "Продать".  
На странице "Контакты" представлена форма обратной связи, при "отправке" данных возвращается страница, информирующая
об успешном POST-запросе и сохранении пользовательской информации в базе данных.  
На странице "Продать" происходит процедура публикации нового продукта.
Сначала предлагается выбрать из существующих или создать новую категорию продукта.
После создания, новая категория становится доступна в списке категорий. Нажав на одну из строк списка
пользователь переходит к заполнению формы нового продукта. При нажатии кнопки "Опубликовать", информация
о продукте сохраняется в базе данных и карточка продукта становится доступной на странице "Каталог".

## Кастомные команды:
rewrite_products_data - данная команда предварительно очищает таблицу catalog_product в БД
после чего наполняет ее данными из фикстуры. Вызов производится с указанием флага
--fixture, в котором передается путь к JSON-файлу фикстуры.  

Пример вызова в терминале:  
python manage.py rewrite_products_data --fixture=fixture/category_fixture.json
При первом запуске можно ускорить процесс наполнения базы данных приложения с помощью
соответствующих фикстур, расположенных в папке fixture в корне проекта, однако, также можно опубликовать
данные "вручную" с помощью интерфейса приложения.

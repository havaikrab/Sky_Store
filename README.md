# Sky Store

## Описание:
Sky Store - это проект, созданный в рамках обучения языку программирования Python.   
Sky Store запланирован как сервер интернет-магазина и блог-ресурса, созданный с использованием фреймворка Django.  
По мере освоения новых приемов работы с Django функционал сервера будет постепенно расширяться.

## Цель проекта:
Главной целью Sky Store является закрепление полученных знаний и навыков работы с фреймворком Django.  
А также повторение материала предыдущих уроков, и применение всех полученных знаний на практике, то есть, для решения  
задач, приближенных к реальным.


## Установка:
1. Запустите IDE на локальном ПК.


2. Клонируйте Sky Store из удаленного репозитория.

    Для этого можно из текущей директории на вашем ПК можно ввести в терминале команду:  
git clone git@github.com:havaikrab/Sky_Store.git


3. Установите зависимости.

    В проекте используется менеджер зависимостей Poetry, установите его, при необходимости.
    Для установки зависимостей введите в терминале команду: poetry install  

4. Для работы приложения используется СУБД PostgreSQL, для запуска  
сервера приложения ее необходимо установить "вручную", создать базу данных  
и указать все необходимые настройки для подключения к ней в файле .env  
в корне проекта. В файле .env_template представлен шаблон с необходимыми настройками для подключения к БД.

## Запуск:
Активируйте виртуальное окружение.  
Примените миграции с помощью команды python manage.py migrate.  
Запустите сервер приложения с помощью команды python manage.py runserver.  
После этого в браузере введите адрес localhost:8000  

## Содержимое:
После запуска вам станет доступна страница "Каталог", на которой, по мере публикации новых продуктов
будет размещена информация о них. На странице размещается до 8-ми карточек продуктов.
Над карточками есть навигационная панель, позволяющая переходить к определенной странице сервиса.
Неавторизованному пользователю доступны страницы "Каталог", "SkyBlog", "Контакты"
и предоставляется возможность зарегистрироваться или авторизоваться на сайте,
также неавторизованный пользователь может просматривать карточки продуктов, но не имеет возможности их редактировать.
В отличие от неавторизованного пользователя, авторизованному доступны также страницы для описания
новых категорий продуктов, публикации новых продуктов и статей. Авторизованные пользователи могут
редактировать описание собственных продуктов каталога. Однако, сразу после публикации или редактирования
продукт не становится доступным на главной странице каталога, пока не получит соответствующее разрешение модератора.
Любой авторизованный пользователь может писать статьи раздела SkyBlog, мо модераторы также имеют разрешения
редактировать и удалять статьи. Собственные личные данные можно изменять в разделе "Профиль".
Отдельными пунктами в профиле предусмотрены возможности безопасной смены пароля и удаления аккаунта пользователя.  
На странице "Контакты" представлена форма обратной связи, при "отправке" данных форма возвращает сообщение,
информирующее об успешном POST-запросе и сохранении пользовательской информации в базе данных.  
Далее пользователем будет называться авторизованный пользователь и будут описаны его возможности в Sky Store.  
На странице "Поделиться продуктом" происходит процедура публикации нового продукта. Если в выпадающем
списке пользователь не может найти подходящую категорию для нового продукта, он может создать новую категорию,
нажав на соответствующую кнопку под формой создания продукта. При нажатии кнопки "Создать категорию продуктов"
открывается таблица с существующими категориями и их описаниями, данная таблица также открывается после создания новой
категории. Нажатие на строку подходящей категории возвращает пользователя к форме создания продукта, где поле категории
уже заполнено подходящим значением. При нажатии кнопки "Сохранить", информация
о продукте сохраняется в базе данных и продукт становится доступной на странице "Каталог" после модерации.
Нажатие на карточку продукта, открывает пользователю основные характеристики этого продукта.
Пользователь-владелец может отредактировать или удалить данный продукт, нажав на соответствующую кнопку
под описанием продукта. На странице "Sky Blog" размещаются карточки-ссылки на статьи различного характера.
Ознакомиться с заинтересовавшей статьей можно нажав на соответствующую карточку. При переходе к материалам
статьи ее счетчик просмотров увеличивается на 1, при сотом просмотре статьи происходит отправка письма "самому себе"
по email, указанному в .env-файле. Также на странице конкретной статьи есть соответствующие кнопки
для ее редактирования и удаления.  
На странице "Написать статью" пользователю предоставляется возможность написать статью :))
В статье необходимо указать ее название и какое-то содержание. Отметка "Опубликовать статью"
сделает ее доступной для просмотра на странице "Sky Blog".

## Категории персонала
К персоналу относятся группы Модераторы и Контент-менеджеры. Пользователи, состоящие в одной или
нескольких группах наделяются соответствующими правами. Модераторы могут допускать и запрещать
публикацию продуктов, могут удалять информацию о продуктах, но не могут ее редактировать, в отличие от
пользователя-владельца. Контент-менеджеры - группа пользователей, наделенная правами редактировать и удалять
контент раздела Sky Blog. Для пользователей, относящихся хотя бы к одной из групп персонала доступна панель
управления, скрытая от обычных пользователей. Для модераторов доступна страница "Публикация продуктов", на которой
отображаются карточки продуктов, ожидающих подтверждения статуса публикации. Страница "Редакция статей" доступна для
контент-менеджеров, здесь размещены карточки статей, не попавших в публикацию. Контент-менеджеры наделены
правами редактировать, удалять, публиковать и отзывать публикацию статей.
Автору статьи недоступна опция "редактировать".

## Кастомные команды:
rewrite_products_data - данная команда предварительно очищает таблицу catalog_product в БД
после чего наполняет ее данными из фикстуры. Вызов производится с указанием флага
--fixture, в котором передается путь к JSON-файлу фикстуры.  

Пример вызова в терминале:  
python manage.py rewrite_products_data --fixture=fixture/category_fixture.json
При первом запуске можно ускорить процесс наполнения базы данных приложения с помощью
соответствующих фикстур, расположенных в папке fixture в корне проекта, однако, также можно опубликовать
данные "вручную" с помощью интерфейса приложения.  
На данный момент в проекте Sky Store работаю 3 приложения users, catalog, sky_blog.
Для каждого приложения описаны кастомные команды, загрузки и выгрузки данных в json-фикстуры.
save-команды - сохраняют данные соответствующего приложения в папке fixture.
load-команды - загружают данные из фикстур.
Формат названия и расположения фикстур строго определен, как fixture/fixture_app_name.json,
где app_name - название соответствующего приложения.  
Список команд:
python manage.py save_users  
python manage.py load_users  
python manage.py save_catalog  
python manage.py load_catalog  
python manage.py save_sky_blog  
python manage.py load_sky_blog  
Для избежания возможных ошибок при выполнении load-команд рекомендуется первой вызывать
команду python manage.py load_users.
